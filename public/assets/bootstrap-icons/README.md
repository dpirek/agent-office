# Bootstrap Icons

Version: 1.13.1
Website: https://icons.getbootstrap.com/
Source: https://github.com/twbs/icons/releases/tag/v1.13.1
License: MIT (see LICENSE)

The complete SVG sprite is vendored locally from the official release archive.
No package manager, CDN, or runtime download is required.

Usage (replace `gear` with any icon name from the catalog):

```html
<svg class="bi" width="20" height="20" viewBox="0 0 16 16"
     fill="currentColor" aria-hidden="true" focusable="false">
  <use href="/assets/bootstrap-icons/bootstrap-icons.svg#gear"></use>
</svg>
```

Keep decorative icons hidden from assistive technology and label their buttons
or links with visible text or an accessible name.
