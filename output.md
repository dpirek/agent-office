# New Jersey Mortgage Marketing Website

Built a polished, responsive mortgage website for **Harborline Mortgage**, including:

- High-impact homebuyer hero section
- New Jersey-focused messaging
- Loan product cards
- Interactive mortgage calculator
- Expandable application process
- Customer testimonials carousel
- Lead-generation form with confirmation toast
- Responsive mobile navigation
- Licensing and compliance footer language
